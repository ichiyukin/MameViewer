# MViewer 設計仕様書 v1.01

作成日：2026-07-05（v1.01：サムネイル一覧ビューを必須機能に格上げ・追記）
題材：旧アプリ **Mangameeya** の後継となる、軽快な漫画・画像ビューア

---

## 1. 概要・目的

- **MViewer** は、ローカルの漫画・画像を快適に閲覧するための Windows デスクトップアプリ。
- 名称は「漫画だけでなく一般画像ビューアとしても普及を狙う」意図（M = Manga / Multi）。
- 題材の Mangameeya、および競合 NeeView を踏まえ、**とにかく軽快な動作**を最優先の絶対目標とする。

### 最優先方針
> **「めくった瞬間に、次のページが既にそこにある」**
> 機能の豊富さより、開く・めくる・閉じるの3動作が一切引っかからないことを最優先する。

---

## 2. 技術構成

| 層 | 採用技術 |
|----|---------|
| フレームワーク | **Tauri 2.x**（軽量・高速・小サイズ） |
| バックエンド | **Rust**（解凍・先読み・リサイズ・キャッシュ） |
| UI | HTML / CSS / **TypeScript**（軽量に。重いUIフレームワークは使わない） |
| Zip 解凍 | Rust `zip` クレート |
| Rar 解凍 | Rust `unrar` クレート |
| 7z 解凍 | Rust `sevenz-rust` クレート |
| リサイズ | Rust `fast_image_resize`（SIMD高速・多フィルター対応） |
| 画像表示 | Tauri カスタムプロトコルで画像を WebView へ渡し GPU 描画 |

### Web アプリを採用しない理由
- Rar / 7z の解凍がブラウザ内 JS では不安定・低速で実用に耐えない。
- ローカルファイル・アーカイブへの自由なアクセスと、軽快さの両立にはネイティブが有利。

---

## 3. 対応ファイル形式

| 種別 | 形式 |
|------|------|
| 圧縮 | **Zip / Rar / 7z**（cbz / cbr 含む） |
| 画像 | JPEG / PNG / WebP / AVIF / GIF |
| アニメーション | アニメGIF / APNG / アニメーションWebP / アニメーションAVIF |
| フォルダ | 画像を直接含むフォルダも開ける |

- 圧縮ファイル内・フォルダ内の画像は**ファイル名で自然順ソート**（`2 < 10` の数値順）。
- アニメーションは 1ファイル＝1ページとして、その場で**自動再生・ループ**（WebView が標準再生）。
  メニューに「アニメーションを再生 / 停止」トグルを用意。

## 4. アーキテクチャ（軽快さの心臓部）

```
┌─────────────────────────────────────┐
│  UI (WebView: HTML/CSS/TS)           │
│   ・<img> をGPU描画                   │
│   ・カスタムプロトコルで画像を即取得    │
└───────────────┬─────────────────────┘
                │ manga://page/{n}
┌───────────────┴─────────────────────┐
│  Rust バックエンド                    │
│  ① ストリーミング解凍                 │  開いた瞬間はファイル一覧だけ読む
│  ② 先読みワーカー（別スレッド）        │  現在±数ページを裏で解凍・リサイズ
│  ③ LRUメモリキャッシュ                │  上限管理で古いページから破棄
└─────────────────────────────────────┘
```

1. **ストリーミング解凍**：圧縮全体を展開せず、必要ページだけ取り出す → 大容量でも即開く。
2. **先読みワーカー**：表示中に前後 N ページを別スレッドで準備 → めくり待ち時間ゼロ。初期値 前後各3ページ。
3. **LRUキャッシュ**：上限を決めて古いページから破棄 → メモリが膨張しない。初期値 512MB。
   リサイズ結果は「ページ番号＋表示サイズ＋フィルター」をキーにキャッシュ。

## 5. 画面構成

- 原則、**画像だけを全画面表示**（Mangameeya 同様の没入感）。
- メニュー・シークバーは、マウスを画面端に寄せた時／キー操作時のみフェード表示。

```
┌──────────────────────────────────────┐
│ [フルスクリーンの画像表示エリア]         │
│         （単ページ or 見開き）           │
├──────────────────────────────────────┤
│ シークバー（下端に寄せた時だけ出現）      │
└──────────────────────────────────────┘
```

## 6. 表示モード

| モード | 内容 |
|--------|------|
| 単ページ | 1枚ずつ |
| 見開き | 2枚並べて表示 |
| 綴じ方向 | **右綴じ / 左綴じ** 切替（見開きの左右順が変わる） |
| フィット | 幅に合わせ / 高さに合わせ / 全体 / 原寸 |
| 回転 | 0 / 90 / 180 / 270（横向きスキャン対応） |
| 見開き自動単独 | 横長画像（見開きスキャンの1枚絵）は見開きモードでも**自動で単独表示**（ズレ防止） |

## 7. 操作系

### 設計3原則
1. **重要機能は5ボタンマウスのみで完結**（キーボード不要で読み切れる）。
2. **3ボタンマウス時は、失われるサイドボタン機能をキーが自動補完**。
3. **全機能は右クリックメニューからも到達可能**（どんな環境でもマウスだけで必ず完結）。

### 5ボタンマウス割り当て

| 入力 | 機能 | 補足 |
|------|------|------|
| ホイール ↓ | 読み進む（次へ） | 見開き時は見開き単位 |
| ホイール ↑ | 読み戻る（前へ） | 同上 |
| S1 単押し | 1ページだけ戻る | 見開きズレ補正 |
| S2 単押し | 1ページだけ進む | 同上 |
| S1 押しながらホイール | 拡大 / 縮小（ズーム） | |
| S2 押しながらホイール | 前 / 次のファイル送り（巻移動） | |
| L ドラッグ | ズーム時の画像移動（パン） | |
| M 押し込み | フルスクリーン切替 | |
| R クリック | メニュー表示（全機能の入口） | |

**サイドボタン二役設計**：押して離すだけ＝ページ移動／押したままホイール＝修飾動作（S1ズーム・S2ファイル送り）。
ホイールを回した場合は、離してもページ移動を発火させない（誤爆防止ロジックを実装）。

### 3ボタンマウス時のキー補完（自動有効）

| 失われる操作 | 補完キー |
|------|------|
| S1 / S2（1ページ移動） | `←` / `→` |
| S1＋ホイール（ズーム） | `Ctrl＋ホイール` / `+` `-` |
| S2＋ホイール（ファイル送り） | `PageUp` / `PageDown` |
| M（フルスクリーン） | `F11` |
| R（メニュー） | `Esc` / アプリキー |

### 右クリックメニュー（全機能の受け皿）
```
表示 ▸ 見開き / 右綴じ・左綴じ / フィット / 回転
移動 ▸ 先頭へ / 末尾へ / 次のファイル / 前のファイル
しおり ▸ 登録・解除 / 一覧
ファイルを開く
設定 / キー・ボタン割り当て
```

### ズームとパンの挙動
| 状態 | ホイール単体の挙動 |
|------|------------------|
| フィット表示中 | ページめくり |
| ズーム中 | 縦スクロール（端まで来たら次ページ）※オン/オフ可 |
- パン（移動）は L ドラッグに固定 → ホイールと衝突しない。

### 未実装（将来検討）
- **クリックゾーン**（画面左右クリックで前後移動）：内部設計上、後から差し込める余地を残す。

### カスタマイズ
- ボタン・キー割り当ては設定画面で変更可能（上記は初期値）。

## 8. シークバー（画面下・横一列レイアウト）

```
┌──────────────────────────────────────────────────────────────┐
│ [◀◀][◀][▶][▶▶] [⇄] │ ▁▁▁▁▁●▁▁▁▁▁▁▁▁▁▁▁▁ │ 12/180 │
└──────────────────────────────────────────────────────────────┘
```

| 要素 | 内容 |
|------|------|
| レイアウト | **横一列（1段）**。ボタンは小さめ・集約 |
| ナビ4ボタン | `◀◀`前の巻 / `◀`1頁戻 / `▶`1頁送 / `▶▶`次の巻（外側=巻移動、内側=1ページ） |
| 綴じ切替 | 4ボタンのすぐ横に配置。**1クリックで右綴じ⇄左綴じトグル**。**アイコン方式**（ツールチップで補足） |
| シークバー | クリック／ドラッグで任意ページへ即ジャンプ |
| ページ表示 | 右端に `現在/総`（例 12/180） |
| バーの向き | **固定（A案）**：`▶`＝常に次へ、数字は左→右で増加。綴じ方向を変えても不変 |
| 表示条件 | 普段は隠れ、マウスを下端に寄せた時にフェードイン |
| ブックマーク印 | シークバー上に登録位置を`▲`で表示、クリックでジャンプ |

## 9. リサイズフィルター（画質）

Rust 側で `fast_image_resize`（SIMD高速）により事前リサイズし、結果をキャッシュ。高画質と軽快さを両立。

### 用意するフィルター（6種）
| フィルター | 特徴 | 向き |
|-----------|------|------|
| ニアレストネイバー | 最速・ドット保持・輪郭カクカク | ドット絵・原寸拡大 |
| バイリニア | 軽量・ややボケる | 低スペック時 |
| バイキュービック(CatmullRom) | 滑らか＆そこそこシャープ | 汎用標準 |
| Mitchell | 滑らか・リンギング少 | ノイズ・アラ抑制 |
| Lanczos3 | 最高品質・シャープ・モアレ抑制に強い | 高画質重視・線画/トーン |
| 面積平均(Box) | 縮小時のモアレ・トーン潰れに最強 | スクリーントーン縮小 |

### 設定方針
- **既定は「おまかせ」**：縮小=Lanczos3 / 拡大=バイキュービック を自動適用。ユーザーは選ばなくてよい。
- こだわる場合のみ「詳細設定」で縮小・拡大フィルターを個別指定＋アンシャープ（0で無効）調整。
- **ファイル別設定は行わない**（設定UIで全体設定のみ）。

### 設定UIイメージ
```
画質（リサイズフィルター）
  モード： ● おまかせ   ○ 詳細設定
  ［詳細設定時］ 縮小: [Lanczos3 ▼] / 拡大: [バイキュービック ▼] / アンシャープ: ▁●▁▁ (0=無効)
```

## 10. ブックマーク（しおり）機能

自動再開（各巻の最終閲覧位置を自動記憶）とは別に、**手動で複数登録できるお気に入り**。

| 項目 | 内容 |
|------|------|
| 操作 | **右クリックメニュー**「しおり ▸ 登録・解除 / 一覧」に集約 |
| 登録単位 | 1ファイルに複数登録可 |
| 一覧 | サムネイル付き。**「このファイル」／「すべて」を切替表示**（全ファイル横断） |
| ジャンプ | 別巻のブックマークをクリックすると、その巻を自動で開いて該当ページへ |
| シークバー印 | 登録ページを`▲`表示、クリックでジャンプ |
| メモ | **なし**（シンプル優先） |
| 保存 | `%APPDATA%\MViewer\bookmarks.json`（サムネイルを埋め込み保存） |

### ファイル移動・削除への対応
- 保存内容：パス＋ファイル名＋ファイルサイズ＋サムネイル画像（埋め込み）。
- サムネイル埋め込みにより、**元ファイルが消えても一覧で中身が分かる**。
- **自動再リンク**（裏で常時有効・操作不要）：別の場所で同名＋同サイズのファイルを開くと、ブックマークのパスを自動更新。
- 見つからないブックマークは一覧で`⚠`グレーアウト表示。**勝手に消さない**。
- **削除優先UI**：`⚠`項目のすぐ横に大きな「削除」ボタン。手間のかかる「再リンク」は隅の`⋯`に格納。
  複数あれば「まとめて削除」ボタンで一括掃除。誤削除に備え直後の「元に戻す」を軽く用意（任意）。

## 10.5 サムネイル一覧ビュー（必須機能）

画像ビューアの必須機能。全ページのサムネイルをグリッド表示して一覧・ジャンプする。

- **開閉**：`A` キー、下部バーの `▦` ボタン、`≡` メニューの「サムネイル一覧」。トグル。
- **表示**：画面全体オーバーレイに全ページを自然順グリッド表示。現在ページをハイライト、各サムネ下にページ番号。開くと現在ページへスクロール。
- **クリック**：サムネクリックでそのページへジャンプし一覧を閉じる。
- **サイズ変更**：上部スライダー（**最小100px〜最大320px／初期160px**）と `Ctrl＋ホイール`。
- **Mangameeya との差別化（重要）**：全枚数を1画面に詰め込まず、**サムネイルは下限サイズ未満に縮小しない**。あふれた分は**縦スクロール**で表示（CSS `minmax(下限, 1fr)`）。
- **性能**：Rust `get_thumbnail(index)` が画像をデコード→長辺360pxへ縮小→JPEG(品質80)化し**キャッシュ**。表示サイズはフロントのCSSで調整（スライダー変更でも再生成不要）。表示は `IntersectionObserver` による**遅延ロード**で数百ページでも軽快。アーカイブ切替時にキャッシュ破棄。
- **対応**：JPEG/PNG/WebP/GIF(1コマ目)等（`image`クレート）。デコード不可時はプレースホルダ。

## 11. 巻移動・履歴・自動再開

- **巻移動**：S2＋ホイール、またはシークバーの`◀◀`/`▶▶`。対象は同フォルダ内の圧縮ファイル群を自然順で辿る。
- **巻末の挙動**：**「ループ」／「次の巻へ移動」をUIで選択可能**。
- **各巻の位置記憶**：巻ごとに最終閲覧ページを個別に記憶。再び開くと自動でその位置へ復元。
- **起動時**：自動再開を基本とし、確認ダイアログを表示。
  ```
  前回の続き（〇〇.zip / 12ページ目）から再開しますか？
        [ 続きから読む ]   [ 最初から読む ]
  ```

## 12. キャッシュ設定UI（誰でも直感で分かる）

MB という数字が分かりにくい人向けに、プリセット＋平易な説明＋使用量バーで設計。

```
動作の軽快さ（メモリ使用量）
  ○ 軽量   （約256MB）非力なPC向け
  ● 標準   （約512MB）おすすめ ★
  ○ たっぷり（約1GB） 高解像度をより滑らかに
  ○ カスタム [___] MB

  ▸ この設定は「先読みしておく画像の量」です。大きいほどページめくりが
    滑らかになりますが、その分メモリを多く使います。迷ったら「標準」でOK。

  現在の使用量:  ▓▓▓▓▓▓░░░░  210 / 512 MB
```
